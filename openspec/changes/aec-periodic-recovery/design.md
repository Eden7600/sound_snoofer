# Design
Neural and classic bridges tolerate a 10-second episode of unstable pairing, ending after 250 ms of consecutive valid callback pairs. Missing reference altogether has a five-second input-audio watchdog. Gaps discard partial audio and re-prime both timelines; no old reference or queued result is replayed. Classic AEC uses its existing rebuild path, and neural variants keep generation invalidation. Other validation and inference faults remain fail-open.

The plugin worker schedules a reset 15 seconds after observing a latched native failure, and at most once per 15 seconds while it persists. Existing new-stream recovery stays immediate. Reset success is not evidence of active processing: clear old stats and show Wait until native stats confirm activity. No automatic retries while inactive, off, unhooked, or removal is unconfirmed. Reset errors retain the cooldown.

Publish a non-persistent aec.retry command and render Retry in the Echo cancellation card. It is available when processing is wanted and an engine/load/status failure exists, but not during loading or unconfirmed removal. The worker rechecks eligibility, resets an existing engine or clears the failed-load attempt, and uses the same cooldown. Never alter mode, strength, engine preference, routing, or restart Voicemeeter. Status on a failed native engine states automatic retry is pending; failure reason remains visible. Tests use explicit timestamps for scheduling and native probes for gap tolerance/budgets, plus GUI command dispatch/disabled state.
