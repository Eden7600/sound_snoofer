# Design
The monitor forwards commands 1, 2 and 3 to input_stage(context, NULL) on the callback thread. Null is an internal lifecycle signal, never a malformed audio buffer to process. AEC invalidates applied generation, processing, expectedReferenceSamples and partial frames; resets reported active/rate/ERLE/delay/failure; leaves destruction/allocation to Configure on the next valid input. Output before that input is ignored. Generation invalidation uses current generation minus one, including unsigned wrap. Existing Go recovery remains fallback for older monitors; errors without a lifecycle event stay latched. This supersedes the assumption that every discontinuity must latch across a new stream, while preserving strict pairing within a stream.
Use the existing native probe to include production pass_through.h and route lifecycle/input/output events through observe. Test each boundary between paired inserts, late output, same-rate restart, existing failure, repeated boundaries and ordinary recovery. Acoustic thresholds remain unchanged; synthetic quality is not hardware listening acceptance.
