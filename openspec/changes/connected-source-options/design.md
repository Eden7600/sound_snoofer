# Design

Extract ASIO hardware selection so planner and microphone eligibility use identical unique WDM companion plus unique ASIO driver rules. Compute selectable mic sources and playback devices from configured regexes and the latest successful snapshot; expose fresh slices in State. Off and Automatic remain usable without inventory. Unavailable current preferences remain saved and visible as preferences but are absent from selectable options. Refresh open lists by value, preserving highlight when possible and falling back to Off/Automatic when the highlighted device disappears; recheck on Enter and validate new device choices in the worker against a fresh snapshot before saving. Do not reject existing unavailable preferences on unrelated edits.

Add optional playback_device to Intent; empty means Automatic for legacy sidecars. A nonempty value must match a configured playback regex. The planner prefers a unique available WDM output with that exact name, otherwise uses existing candidate priorities. Offer only unique, available, nonvirtual configured WDM names in stable name order. Keep output ownership restricted to configured regexes, so arbitrary unmanaged outputs are never silently taken over. Selecting a different endpoint within the same bus still uses device debounce and verified transition gating. Preserve lowest-free bus placement, ASIO A1 reservation, recording and mic preferences.

Generalize the existing picker with per-instance options, row key and title. Place Playback Device in Computer Audio before source toggles. Controls use local draft choices and existing ordered edit batches. Refreshes and acknowledgements must update the correct picker value for source versus playback. No renderer native writes. Test disappearance/reconnect, ambiguity, driver-only Volt, stale confirmation, persistence, draft batching and fallback/migration. Preview smoke only; no live audio changes for validation.
