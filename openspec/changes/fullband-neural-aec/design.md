# Design

Run a parallel mono 48 kHz WebRTC AEC3 on the neural worker using the same captured microphone and averaged playback reference. The existing LocalVQE path receives the original microphone/reference unchanged. Only the high-frequency portion of AEC3 output is mixed back; raw microphone high frequencies never bypass echo control. Existing model files and bounded queues are reused. AEC3 full-band processing is worker-owned and recreated on generation changes together with neural/resampler state.

Combine with a complementary 129-tap linear-phase Blackman-windowed sinc crossover around 6 kHz, safely below the neural resampling edge. Delay the shorter AEC3 branch to match the neural 256-sample hop and resampler delays. Measure the bundled AEC3 signal delay and verify the fixed compensation before release; do not guess its latency. Both crossover branches share the same FIR delay. Validate unity reconstruction for equal aligned signals, stop-band separation, near-only high-frequency preservation, and echo attenuation; retain old-model streaming parity and gap-recovery tests.

A single new engine ID localvqe-full uses the v1.3 voice model; existing IDs and defaults are unchanged. A separate native constructor selects hybrid processing without changing the existing constructor ABI. At other host rates the engine passes through and the GUI says Needs 48 kHz. GUI status describes 48 kHz mono / hybrid and processing latency; Strength remains unavailable. Persist/switch uses the existing confirmed-detach lifecycle. Do not silently enable the new mode in personal configuration. Listening comparison remains hardware acceptance: preserving bandwidth is measurable, but subjective quality improvement is not guaranteed.

Measured transport delays are 430 samples for AEC3 and 834 samples for neural hop plus resamplers; compensate by 404 samples. Synthetic tonal double-talk exposes AEC3 upper-band gating (about 20 dB attenuation at 10 kHz), despite near-only preservation and echo-only reduction. This optional mode does not guarantee preserved treble during double-talk; retain that measurement and require listening acceptance.
