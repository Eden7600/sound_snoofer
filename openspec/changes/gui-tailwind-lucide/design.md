# Design

## Tailwind build
- **Dependencies:** `@tailwindcss/cli` and `tailwindcss` v4 as pinned dev dependencies in package.json/package-lock.json (npm is the lockfile of record).
- **Input:** `app/web/tailwind.css` contains:
  - `@import "tailwindcss" source(none)`;
  - explicit `@source` entries for `app.js`, `index.html` and `icons.mjs`;
  - an `@theme` block of design tokens: colors `canvas`, `panel`, `raised`, `line`, `ink`, `muted`, `active`, `attention`, `critical`, the meter colors and the UI font.
  - Base element rules live in `@layer base` (body, form controls and focus outline): plain element styling, not custom classes.
- **Output:** `app/web/dist/app.css` (minified), generated by `npm run css`. `app/web/dist/` is gitignored except `.gitkeep`.
- **Embedding:** Go embeds `all:web/dist` alongside the other web files, so `go build`, `go vet` and `go test` compile without Node. A binary built without CSS is rejected only by `scripts/build.ps1`.
- **Who generates it:**
  - `scripts/build.ps1` runs `npm run css` before compiling and fails if `dist/app.css` is missing or empty;
  - `scripts/check-gui.cjs` and `scripts/check-desktop.cjs` generate CSS before serving;
  - `scripts/check.ps1` inherits it through the build.
- **Classes:** JavaScript builds class strings only from complete utility literals (Tailwind scans source text). Tone helpers return utility strings, for example `tone()` → `text-active`. State toggles use `data-*` attributes with Tailwind data variants (`data-[tone=active]:border-l-active`) or swap complete literals.
- **Custom CSS:** none beyond tokens and base element rules. Exceptions:
  - the meter's dynamic `clip-path`, set as an inline style from JS;
  - the dialog `::backdrop`, via the `backdrop:` variant.

## Icons
- **Source:** `lucide-static` (pinned dev dependency). `scripts/vendor-icons.cjs` copies the chosen SVGs into `app/web/icons.mjs` as an `icon(name, classes)` factory. The factory builds an inline `<svg>` with `aria-hidden="true"`, `stroke="currentColor"` and a Tailwind size class, so icons inherit tone colors. The file carries the Lucide ISC notice and is committed: it is source, regenerated only when the set changes.
- **Sidebar:**

## Test hooks
Checks select by role or accessible name where possible, and otherwise by `data-part` attributes. Examples: `data-part="strip"`, `"clip"`, `"scene"`, `"app-card"`, `"deck-key"`, `"dial"`, `"inspector"`, `"setup"`, `"summary"`, `"not-monitored"`, `"app-times"`, `"app-error"` and `"endpoint"`. State uses `data-tone` and `data-state` attributes instead of classes. Hooks never carry styling.

## Visual baseline
Same layout, palette, sidebar, cards, deck grid and responsive breakpoints (1500/1120/850 px); exact pixels may differ. The contract's GUI reference images are regenerated and inspected.
