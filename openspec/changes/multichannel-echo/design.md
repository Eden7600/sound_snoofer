# Design
## Reference
Expose eight explicit channel indexes from the selected A bus through EchoTargets and Config. All are retained independently; no layout guess based on device name or saved strength. Stereo upmix in the speaker is represented by its stereo input, while true 5.1 reaches independent adaptive reference filters. Channels absent from an insert buffer are an error, not silently synthesized. AEC3 multichannel rendering and capture are explicit. Disable detect_stereo_content because the vendored detector inspects only channels 0 and 1. Silent unused bus slots are legitimate.
## Framing and timing
Process microphone samples incrementally, completing 10 ms frames and consuming the output queue per sample. This preserves a fixed 10 ms shim delay and eliminates the old four-frame FIFO truncation for large callbacks. Prime output with 10 ms silence as the existing implementation actually does. Accumulate reference samples into a single planar 10 ms frame and call ProcessReverseStream directly from the output insert; no reference backlog FIFO or drop-oldest behavior remains. The callback contract is one input then one output at matching rate/size. Validate pairing and buffer sizes, check reverse-stream errors, and latch failure with mic pass-through on any discontinuity. Output insert never modifies playback. AEC3 estimates remaining acoustic/device delay; do not invent a manual offset without evidence. Midstream config/rate changes clear framing state.
## Validation and limits
Extend tools/aec-probe (do not duplicate it) for stereo, phase-opposed stereo, center-only, surround-only and independent six-channel echo; supported rates, buffer sizes including non-10ms and larger-than-old-FIFO, variable sizes, exact frame counts, bypass and fault pass-through. Measure local voice in pauses and simultaneous double-talk separately. Keep stereo acoustic baseline thresholds; report synthetic results honestly. Test invalid native config and ABI version rejection. Run Go tests/vet, strict OpenSpec validation, canonical build and native probe before normal host relaunch. Preserve personal settings and unrelated dirty files. Hardware acceptance requires listening to both speaker upmix and discrete surround, including double-talk and CPU/latency under load.
## Alternatives
Compare primary documentation for SpeexDSP and neural AEC candidates. Engine replacement requires evidence against the same workload; retain AEC3 for this implementation.
