# Design

Reuse the native AEC insert ABI and plugin lifecycle. Add a model-path constructor for the LocalVQE companion; use the existing Configure/Stats/Reset/Hook/Close wrapper. CPU inference runs on one owned native worker, never on the Voicemeeter callback. Fixed-capacity SPSC queues connect callback and worker; overflow, missing reference, invalid samples or an output deadline miss latch pass-through with an error, never replay stale processed audio. Stream/config generations invalidate all pending data. Detach acknowledgement is required before destruction and switching.

Frame capture and corresponding output reference together. Mono mic is the mean of the two managed input channels; mono reference is the mean of all eight selected playback channels. This cannot independently cancel surround speakers or preserve stereo microphone content; state that limitation. Use the bundled WebRTC sinc resampler for 16/32/48 kHz host rates and 256-sample LocalVQE hops. Buffer a fixed bounded processing delay of 64 ms plus one device callback block (reset framing if the block grows); include the model hop and resampler delay in the displayed latency; prime with pass-through and only report Active after processed audio is delivered. Report processing latency separately from unknown echo-delay/ERLE; do not invent quality metrics.

Save-before-apply engine preference. On a changed selection bypass/detach old engine, clear stale status, close it, and open selected model. If detach fails retain old allocation safely and report error; if loading fails pass through, allow choosing AEC3 again. Strength applies only to AEC3. Auto/On/Off retains its meaning. Model loading occurs on the existing plugin worker, with GUI remaining responsive and Wait status published before loading. No silent fallback to a different selected engine.

Fetch pinned LocalVQE/GGML commits to .local, preserve licenses, download weights with pinned SHA256. Build CPU only with installed MSVC and portable verified CMake; no global installation. Application builds remain scripts/build.ps1 -> bin/snoofer.exe. AEC3 stays default for existing configurations. Tests exercise real model inference, native framing/reset/deadlines, safe switching and GUI controls. Synthetic quality results do not establish superiority; real-room listening remains an explicit unchecked acceptance task.
