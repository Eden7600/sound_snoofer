# Design

Callback ordering is not timestamped by our insert ABI. Once pairing is lost, neither reusing the previous reference nor processing the pending microphone against the next reference is justified. Discard pending/partial audio and advance the existing generation, so the worker resets its model/resamplers and the callback rejects old results. Reuse existing pass-through warm-up and latency; do not alter the model or invent missing reference samples.

An audio-thread-only recovery episode owns unstable input-sample and consecutive paired-sample counters. A gap begins recovery and resets the consecutive-pair counter. One second of continuous matching output ends recovery. New gaps within an episode do not reset its two-second input budget; expiry latches the existing missing-output error. Absence of reference for one second still latches through the existing startup watchdog. Unpaired output resets the generation and is discarded. A control/stream reset starts a fresh episode; a generation advanced by discontinuity preserves the existing recovery budget. A latched failure is never cleared by another gap.

No callback allocation, lock, sleep or neural inference is added. Both neural variants share this bridge. AEC3 behavior stays unchanged. Tests inject omissions/duplicates in each rate/block case, check bit-exact bypass, resumed Active, repeated-gap and no-reference timeouts, and run direct-model fixture parity both fresh and after a midstream gap. These tests establish recovery without claiming the actual host-side source of the gap is known. Preserve the user's selected localvqe-voice engine and no-argument launch after the canonical build.
