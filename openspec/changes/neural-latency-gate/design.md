# Design
Replace Sleep(1) polling with a worker-owned auto-reset Windows event signaled after input publication and during shutdown. Queues and inference remain off the callback; the callback never waits. Measure peak input queue age and worker packet processing time with QPC, plus gap/underrun counts, through an additive native diagnostics export and GUI Timing status. Measurements cover the current engine lifetime, including warm-up, and are not end-to-end device latency.

Trial a 32 ms fixed output buffer instead of 64 ms, retaining callback-block headroom, model-hop and resampler delays. Report approximately 61 ms neural / 63 ms hybrid at 48 kHz with 512 samples. Revert to a larger tested buffer if real-model deadline checks fail. Verify streaming parity at the new offset, all supported rates/blocks, repeated pre-roll resets and sustained operation.

Gate only the echo-processed upper branch from neural output energy. Use a 5 ms attack / 60 ms release power envelope, a soft RMS transition from 0.0003 to 0.003 (approximately -70 to -50 dBFS), and 2 ms opening / 40 ms closing gain smoothing. Start closed and reset with the hybrid worker. Keep the low branch untouched, retain AEC3 upper echo control, no raw high-band bypass or lookahead. This trial may suppress isolated high-frequency or very quiet speech; thresholds require listening acceptance. Test closed/open behavior and transitions, crossover reconstruction, echo-only suppression, and actual callback gating.
