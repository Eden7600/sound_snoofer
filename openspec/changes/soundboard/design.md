# Design
Soundboard depends directly on audio. Audio settings reserve VAIO3 (Potato strip 7), reject its use as ordinary playback, and own its A/B2/B3 sends in the existing routing plan. Reservation remains configured when soundboard is disabled so the audio worker clears sends on restart. B1 remains recording-owned. The plugin sets an immutable route policy; microphone and monitor destinations default on. Mic stack and mic mute do not control clips. Existing output bus mute/gain remain respected.

Playback uses a small Windows DirectShow companion with an explicitly named DirectSound renderer and RenderEx restricted to existing renderers. It never falls back to the Windows default or uses the Voicemeeter recorder. All COM work belongs to one locked plugin worker thread. One graph exists at a time; another clip stops it first. Completion, failure, loss of audio readiness, cancellation and shutdown release it. Playback never retries automatically. Preview does not load the native companion or play. Route readiness requires fresh observed audio state and matching reserved sends before Run.

Only regular MP3 files directly inside the configured folder are catalogued, sorted by filename, with stable name-derived control IDs. Rescan every five seconds. Missing folder/files and decoding/device errors remain local diagnostics. Commands are bounded and stale catalogue requests are rejected.

Stream Deck pages may opt into an auto_controls prefix. Matching press controls fill only unbound, unshared positions, sorted by label. Manual bindings take precedence; overflow adds runtime pages with reserved IDs. Saved layouts remain user-owned; the editor exposes the prefix and manual bindings. The personal configuration gets a Soundboard page with Stop at key 35, with Home unchanged. Disabling the plugin leaves the page empty except unavailable static bindings.

Matching PNG/JPEG/WebP/GIF files supply clip artwork (.png, then .jpg, then .jpeg, then .webp, then .gif, case-insensitive basename). GIF icons use the first frame on its logical canvas; animation is not played. Detect actual image content rather than trusting the extension (downloaded WebP files may be named .png). Decode bounded files (8 MiB, at most 4096px per dimension), fit rectangular images proportionally inside a transparent 64px square thumbnail without cropping or stretching, and carry an immutable base64 Artwork string through semantic controls and deck frames. Missing/invalid images retain the play icon without disabling playback; image diagnostics remain in TUI. Refresh artwork on folder rescan. Artwork replaces only the central symbol; filename and state remain visible. Cache keys include artwork.

The Soundboard page's first dial binds soundboard.volume. The audio dependency supplies the observed VAIO3 gain and a bounded command handler; writes reuse the serialized gain controller with an explicit absolute-zero reset operation. Gain affects both soundboard destinations, respects the existing -60..+12 dB range and native readback, and never mutes. No gain reset occurs on launch. Other dial behaviors and bindings remain unchanged.

No mixing, recursive folders, playlists, recorder reuse or media-framework dependency.
