# Soundboard plugin
## Why
Play local MP3 clips from a dedicated Stream Deck page through Voicemeeter without taking over recording.
## What Changes
- Optional soundboard plugin depending on audio, disabled by default; manually enable the personal configuration.
- Folder catalogue, single-clip replacement, Stop, native Windows playback to an explicitly selected VAIO3 renderer.
- Audio-owned VAIO3 routing to B3 and the current playback bus, independent of microphone processing.
- Opt-in automatically populated Stream Deck pages preserving manual bindings and Home.
## Impact
Audio routing reserves VAIO3 explicitly; Windows build adds a native playback companion. No recorder transport changes or new third-party dependency.
