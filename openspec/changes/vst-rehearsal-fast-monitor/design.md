## Design
Monitor presentation changes only: pre/post retain their saved meaning, recording stage stays Pre/Post.
Persist recording.to_vst and recording.loop booleans (legacy false). To VST requires active microphone source and Element mode; switching Off/Direct normalizes it off. During rehearsal suppress all physical mic sends and AUX-to-B3; feed native Recorder.B2 to Element, keep AUX-to-B2 off and B1/B3 tape sends off. Disable tape A sends to avoid simultaneous dry/processed playback. Monitor Post-VST listens to AUX; Pre-VST routes tape to the selected physical output instead (while B2 still feeds Element). Mic capture is inactive during rehearsal; computer capture remains configured. Disable rehearsal restores normal live mic routing without altering recorder transport. Source Off disconnects recorder B2 as well as existing mic/return sends.
Manage recorder B2 and Loop through verified topology operations. Own tape A/B sends while rehearsal is enabled; on exit clear tape A sends previously owned by rehearsal, using explicit operations derived from observed B2. Preserve file, gain, format, capture arming and unrelated settings. Rehearsal Playing is permitted by recording conflict checks only with B1/B3 off; Recording remains a conflict. Start Recording rejects rehearsal. Play requires rehearsal and converged routes, stopped transport, and live ownership; use Recorder.replay to start at zero, confirm Recorder.play. Stop uses existing one-shot stop. No automatic start/retry on launch or uncertain result. Loop affects native Recorder.mode.Loop; no process or file loader added. User loads a recording using Voicemeeter.
Preserve break-before-make across tape and strip sends: disable old tape send before enabling physical mic feed; disable physical feeds before tape B2 enable. Disable Post monitor before switching to tape Pre monitor. Parameter readbacks include recorder sends and loop; numeric setters delegate allowlisted recorder values. Existing recorder protection must not fight intentional rehearsal B2.
Latency: skip unchanged transition operations. Numeric-only transactions use optional ParameterSnapshot backend with a copied inventory from the latest full observation; refresh every assignment and numeric parameter, detect edition/owned-cell drift, poll 5 ms for numeric verification. Full inventory checks before and after transaction; device-changing transactions retain full snapshots and device debounce. Inventory may change during a numeric-only transaction; final full observation rejects changed inventory and next pass replans. No guarantee of 20 ms wall-clock completion. Keep single owner OS thread and no new goroutines. Add read-only timing evidence if feasible.
## Validation
Deterministic tests for labels, normalization, rehearsal feedback isolation, pre/post monitoring, transport/loop guards, fallback backend, reduced full-read count, drift, failure/cancellation; full tests, vet, build, strict validation and isolated preview keyboard smoke. Physical playback/listening and measured live mutation latency are separate acceptance and must not be inferred from mocks.

Tape Playing with all B sends off does not require capture arming readiness; this permits leaving rehearsal while native playback continues. Capture readiness remains mandatory for Record.

Persist an internal tape_routing_managed marker once rehearsal is enabled. Thereafter manage tape A/B sends even after rehearsal is disabled, so partial application/restart cannot leave a dry tape send behind after B2 is cleared. Existing profiles that never enabled rehearsal retain unowned A sends.
